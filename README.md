# 손으로 놀자! 모션게임 — 화면 디자인 PNG 세트

## Claude에게 전달할 내용

이 폴더의 PNG를 사용해 reference/original-design.png의 메인 메뉴와 로딩 화면을 구성해 주세요.
기존 게임 기능은 이 자료에 포함되어 있지 않습니다. 이미지 파일을 조합해 화면을 구현하는 자료입니다.
전체 화면 배경 2개와 카드 속 배경 3개는 불투명하고, 나머지 요소는 투명 PNG입니다.
생성형 이미지로 개별 요소를 다시 제작했으므로 원본과 세부 형태가 완전히 같지는 않습니다.

## 화면 조립 방법

1. 16:9 화면을 기준으로 배경은 cover로 채웁니다. 좌우 장식보다 중앙 UI가 우선입니다.
2. 로고는 상단 중앙, 손 홈 아이콘은 좌측 상단, 설정은 우측 상단에 둡니다.
3. 메인 화면에는 민트/피치/블루 카드 3개를 나란히 둡니다. 카드 테두리와 하단 버튼 영역은 CSS로 구성합니다. 둥근 모서리 안쪽에 card-backgrounds의 배경을 cover로 놓고, 그 위에 art의 투명 캐릭터 그림을 contain으로 놓고, 게임명과 시작 버튼을 별도로 겹칩니다.
4. 시작 버튼 바탕 위에 재생 아이콘과 실제 텍스트 '시작하기'를 별도 요소로 놓습니다.
5. 로딩 화면은 구름 배경 위에 로고, 손 마스코트, '신나게 놀 준비 중!', 로딩바 순서입니다.
6. 로딩바 채움은 이미지 전체를 가로로 찌그러뜨리기보다 컨테이너의 overflow:hidden으로 드러나는 폭을 바꿉니다. 채움 이미지와 트랙에는 투명 여백이 있으므로 manifest의 visibleBounds를 기준으로 안쪽에 맞춰 주세요. 별은 채움 끝 위치를 따라 이동합니다.
7. '70%' 같은 숫자는 실제 준비 진행률에 연결합니다. 완료 전에 100%라고 표시하지 않습니다.
8. 카드명·버튼 문구·안내·퍼센트·상태 문구는 PNG에 굽지 말고 HTML 텍스트로 렌더링합니다. '2인 대결' 배지와 준비 표시 초록 점은 CSS로 만들면 색과 상태를 바꾸기 쉽습니다.
9. 그림은 contain으로 종횡비를 유지합니다. PNG별 투명 여백이 다르니 manifest의 경계를 참고하세요.
10. 카드 아트는 하나의 PNG에 묶인 구성입니다. 내부 벌레/음식/풍선을 각각 움직일 수 있는 개별 스프라이트는 이 세트에 포함하지 않았습니다.

## 무궁화 꽃이 피었습니다 (mugunghwa/)

카메라가 술래가 되는 몸놀이 게임입니다. 메뉴의 4번째 카드(또는 숫자 4 키)로 들어가요.

- "무궁화 꽃이 피었습니다~" 동안 제자리 달리기·팔 흔들기 → 내 캐릭터가 술래 쪽으로 가요.
- "얼음!" 때 움직이면 걸려서 뒤로 가요. 먼저 도착하면 이겨요.
- 설정: 혼자/둘이서(왼쪽 1P, 오른쪽 2P) · 술래 눈치(너그러움·보통·매의 눈) · 술래 목소리 켜기/끄기
- 몸 인식(MediaPipe Pose Lite)은 브라우저 안에서만 돌아가요. 필요한 파일은 `mugunghwa/vendor/`에 같이 들어 있고,
  웹 주소로 열면 페이지가 같은 사이트 밖으로는 아무것도 보내지 못하게(Content-Security-Policy) 막혀 있어요.
- 홈 화면에 설치할 수 있어요(PWA). 한 번 열어 두면 인터넷 없이도 놀 수 있어요.
- 움직임 기준을 맞춰 보고 싶으면 주소 끝에 `?debug`를 붙이면 화면 아래에 숫자가 보여요.
